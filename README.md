# Storage Cluster Monitoring System

Distributed system for monitoring storage nodes using TCP sockets.

## Architecture
- 9 Client Nodes
- 1 Central Monitoring Node
- TCP Bidirectional Communication
- SQLite Persistence
- Web Dashboard

## Tech Stack
- Python 3.11
- Flask
- SQLite
- psutil
